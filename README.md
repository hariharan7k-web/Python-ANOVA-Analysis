Analysis of Variance (ANOVA) Using Python

📌 Project Overview

This project demonstrates Analysis of Variance (ANOVA) using Python to compare the means of multiple groups and identify statistically significant differences.

It includes practical implementations of One-Way ANOVA and Two-Way ANOVA, along with statistical assumption checks and post-hoc testing methods.

🎯 Objectives

- Understand the concept of ANOVA.
- Perform One-Way and Two-Way ANOVA.
- Compare means of multiple groups.
- Check statistical assumptions.
- Calculate Effect Size using Eta-Squared.
- Perform post-hoc analysis using Tukey HSD.
- Apply the Kruskal-Wallis non-parametric test.

🛠️ Tools and Technologies

- Python
- NumPy
- Pandas
- SciPy
- Statsmodels
- Google Colab / Jupyter Notebook

📚 Topics Covered

1. Introduction to ANOVA
2. One-Way ANOVA
3. Two-Way ANOVA
4. ANOVA Assumption Checks
5. Shapiro-Wilk Normality Test
6. Levene's Test
7. Effect Size (Eta-Squared)
8. Tukey HSD Post-Hoc Test
9. Kruskal-Wallis Test
10. Applications in Machine Learning and AI

📊 Key Analysis and Results

- Performed One-Way ANOVA to compare fertilizer effects on cotton yield.
- Obtained an F-statistic of 0.1014 and p-value of 0.9045.
- Applied Two-Way ANOVA to study the effects of sunlight and watering frequency on plant growth.
- Identified statistically significant effects of water and sunlight.
- Calculated Eta-Squared to measure effect size.
- Performed Tukey HSD for pairwise group comparisons.
- Compared ANOVA results with the Kruskal-Wallis test.
